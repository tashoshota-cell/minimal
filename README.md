# Minimal v1

自分用の「1日1つ手放す」記録アプリです。

## 機能
- 手放したものを記録
- カテゴリ / 手放し方 / 日付 / 売却額 / メモ
- 累計・今月・連続日数・売却額集計
- 履歴検索 / 削除
- ブラウザ内に自動保存（localStorage）
- JSONバックアップ
- PWA / オフライン対応
- iPhoneのSafariから「ホーム画面に追加」でアプリ風に利用可能

## GitHub Pages
1. このフォルダの中身をGitHubリポジトリ直下へアップロード
2. Settings → Pages
3. Build and deployment → Deploy from a branch
4. Branch: main / /(root) → Save
5. 表示されたURLをiPhoneのSafariで開く
6. 共有 → ホーム画面に追加

※ データは各ブラウザ端末内に保存されます。
